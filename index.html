\[ y_i = \beta_0 +\beta_1 x_i + \varepsilon_i \\ \varepsilon_i \sim \mathcal{N}(0, \sigma^2) \]

  • \(y_i\) is the response (dependent variable) for observation \(i\)
  • \(x_i\) is the predictor (independent variable)
  • \(\beta_0\) is the intercept and \(\beta_1\) is the slope
  • \(\varepsilon_i\) is the random error term
  1. Linearity. The conditional mean of \(Y\) is a linear function of \(x\) and is correctly specified:
  2. Zero-mean errors (exogeneity). The errors have mean zero and are uncorrelated with the predictor:
  3. Homoscedasticity (constant variance).
  4. Independence (no autocorrelation). Errors are uncorrelated across observations:
  5. Variation in the predictor. The \(x_i\) are not all identical, so the slope is identifiable:
  6. Normality of errors (needed for exact small-sample inference, not for unbiasedness of the least-squares estimators):

\[ E(y_i) = \beta_0 +\beta_1 x_i \\ y_i \sim \mathcal{N}(E(y_i), \sigma^2) \]

The mean of the distribution of the observed values of each variable for each value of the predictor is a linear function of the value of the predictor Only the mean of the distribution of the outcome varies with the predictor

\[ E(bmi_i) = \beta_0 +\beta_1 age_i \\ bmi_i \sim \mathcal{N}(E(bmi_i), \sigma^2) \\ \\ \beta_0 = 18\ Kg/m^2 \quad \quad \beta_1 = 0.2\ Kg/m^2/year \]

What if it is not the case?

. . .

\[ \mathbb{E}[Y_i \mid x_i] \neq \beta_0 + \beta_1 x_i \]

Example Data

set.seed(2709)    

# Generating the predictor
X <- seq(from = -5, to = 5, by = .1) 

# Generating the 'true' outcome 
B <- t(bs(X, knots = seq(-5, 5, 1), degree = 3, intercept = FALSE))  # creating a B-spline 
num_basis <- nrow(B)
a0 <- 1  # Intercept 
a1 <- 0.2  # slope of the linear term
a <- rnorm(num_basis, 0, 1) # random coefficients for the B-spline  
Y_true <- as.vector(a0 + a1 * X + a %*% B) # generating the output

# Adding some noise 
Y <- Y_true + rnorm(length(X), 0, .20) # adding noise

# Consolidate
D <- data.frame(cbind(X, Y, Y_true))

Fractional Polynomial (fractional powers of the predictor)


Definition: A fractional polynomial models non-linear covariate effects using powers chosen from a predefined set (typically -2, -1, -0.5, 0, 0.5, 1, 2, 3).

Algorithm: It cycles through continuous variables, using backward elimination and closed-test procedures to decide if a variable should be excluded, kept linear, or transformed into a 1st-degree (FP1) or 2nd-degree (FP2) fractional polynomial.
